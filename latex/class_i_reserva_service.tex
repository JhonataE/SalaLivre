Interface abstrata para o serviço de gestão de reservas. 

Define os métodos obrigatórios para persistência e consulta de agendamentos, permitindo o desacoplamento entre a interface e a implementação real (\doxylink{class_reserva_lib}{Reserva\+Lib}).
