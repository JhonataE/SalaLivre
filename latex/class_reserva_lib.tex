\doxysubsection{Detailed Description}
Implementação concreta do serviço de reservas (Componente de Persistência). 

Esta classe encapsula a lógica de armazenamento de dados em memória utilizando um QMap, herdando da interface \doxylink{class_i_reserva_service}{IReserva\+Service} para garantir o desacoplamento do sistema.
